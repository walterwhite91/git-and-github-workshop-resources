Real-World Git Command Library

Categorized reference manual for everyday local and cloud development workflows.

1. Configuration & Setup

Run these commands when configuring a brand-new computer environment or starting a new repository assignment from scratch.

git config --global user.name "YourName" Identifies your code authorship globally.
git init Turns the current local directory into an active Git repo.
2. The Daily Code Pipeline

The basic loop you run through multiple times a day while building features or fixing system bugs.

git add . Stages *all* modified and new files for the upcoming commit.
git commit -m "feat: core tracking" Takes an encrypted historical snapshot of staged changes.
3. Branch Management

Essential for production environments where you must safely isolate experimental work away from your core codebase lines.

git checkout -b feature/login Creates a new feature branch and switches directly into it.
git branch -a Lists all tracking branches across both local and remote streams.
4. The Git Stash (Save State)

Invaluable when you need to switch tasks immediately but aren't ready to commit half-written, broken code.

git stash Shelves your uncommitted files into a temporary storage drawer.
git stash pop Restores the most recently stashed changes back into your workspace.
5. Inspecting Project History

Commands to track down bugs, review past log entries, or figure out exactly who altered a line of logic.

git log --oneline --graph --all Displays a beautiful, scannable ASCII tree layout of all history.
git blame file.js Shows authors and commit stamps for every single line inside a file.
6. The Panic Buttons (Undo)

Mistakes happen. These commands allow you to safely rewrite or overwrite broken states to return to safe baselines.

git checkout -- filename.html Discards local uncommitted updates to match the last commit.
git reset --hard HEAD~1 Nukes the absolute latest commit completely out of existence. Use with extreme caution!
